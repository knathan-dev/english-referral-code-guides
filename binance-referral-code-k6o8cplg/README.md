## Build a cost list with separate entries

Use four headings in your own notes: acquisition, transfer in, trading, and transfer out. Leave a heading empty if that step is not part of your plan. This prevents a broad “all-in fee” number from hiding which service caused a charge.

That does not mean that another platform will send the assets for free. It also does not convert every payment-provider purchase into a free deposit.

For trading, use the actual product and account fee information. For a possible withdrawal, use the charge displayed for the asset and supported network when you are considering that transaction. Avoid carrying today's withdrawal quote into a long-term projection as though it were a guaranteed fixed cost.
