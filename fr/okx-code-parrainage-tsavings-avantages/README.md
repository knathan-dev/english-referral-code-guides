Si vous utilisez un outil externe, distinguez soigneusement son autorisation d’accès et votre relation de parrainage. L’une concerne ce que l’outil peut faire ; l’autre concerne une condition commerciale. Aucune de ces deux informations ne prouve automatiquement l’autre.

## Décrivez le besoin avant de connecter un outil

Commencez par une tâche précise : consulter des informations, préparer un suivi ou utiliser une fonction dont vous comprenez les effets. N’accordez pas un accès simplement parce qu’un écran le propose. Listez les fonctions réellement nécessaires et consultez les explications officielles correspondantes. Cette approche n’affirme pas qu’un outil particulier est bon ou mauvais ; elle aide à comparer la demande d’autorisation avec votre besoin. Si vous ne pouvez pas expliquer pourquoi une permission est nécessaire, clarifiez ce point avant de poursuivre.

## Confirmez TSAVINGS dans le parcours commercial

Utilisez l’invitation fournie et vérifiez l’attribution du code ainsi que la couverture des frais. Conservez cette confirmation à part de vos informations techniques. Un outil qui reconnaît votre compte ne démontre pas que le bénéfice de parrainage a été appliqué. Inversement, une invitation confirmée n’autorise aucun tiers à intervenir sur vos fonds. ## Identifiez le compte qui produit les opérations

La documentation OKX traite des sous-comptes, des modes de compte et des connexions API. Utilisez-la pour comprendre la configuration que vous avez réellement choisie, sans supposer que toutes les structures partagent automatiquement les mêmes conditions. Lorsque vous examinez un frais, identifiez le compte et le produit concernés. Une vue agrégée peut être pratique pour suivre l’activité, mais elle ne remplace pas les détails nécessaires à la vérification d’une offre. Gardez un nom clair pour chaque périmètre que vous utilisez.

## Ne transmettez pas un secret pour prouver un rabais

Une demande sur le pourcentage de réduction devrait porter sur les conditions, l’attribution et les frais concernés. Elle ne justifie pas de communiquer des secrets d’API ou des codes de connexion à une personne qui propose de vérifier l’offre. Utilisez les procédures officielles pour les autorisations techniques et les canaux appropriés pour l’assistance commerciale. Si une demande mélange les deux sans explication, faites préciser sa finalité. La simplicité d’une promotion ne doit pas masquer les conséquences d’une autorisation sensible.

## Comparez le coût total de la solution choisie

Une réduction de commission ne couvre pas automatiquement les frais facturés séparément par un outil. Dans un exemple fictif, 20 unités de frais éligibles avec une réduction confirmée de 20 % deviennent 16. Si un service distinct coûte 8 unités, ce coût reste à examiner séparément ; l’économie de 4 ne le fait pas disparaître. Les montants ne décrivent aucune offre réelle. Ils illustrent la nécessité de comparer la solution complète avec votre besoin, sans présenter le pourcentage de parrainage comme une réduction universelle.

## Questions fréquentes

### TSAVINGS donne-t-il accès à une API ?

Le code identifie l’invitation commerciale fournie. Les possibilités techniques et leurs autorisations suivent la configuration et les procédures applicables. Ne déduisez pas un droit d’accès ou une permission particulière de la présence du code.

### Toutes mes sous-structures reçoivent-elles forcément le même bénéfice ?

Il faut le vérifier pour le compte et le produit concernés. La documentation explique les configurations, mais la couverture commerciale doit être confirmée. Une organisation commune ne prouve pas une attribution identique pour chaque opération.

### Puis-je additionner le rabais à toutes les réductions d’un outil ?

Seulement si les conditions confirment leur combinaison et leurs bases respectives. Deux annonces peuvent parler du même coût ou de services distincts. Comparez les charges nettes réelles plutôt que de sommer des pourcentages sans contexte.
