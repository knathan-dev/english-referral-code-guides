Un pourcentage de réduction plus élevé ne suffit pas à identifier le coût final le plus bas. Comparez d’abord les commissions avant avantage, puis les réductions applicables. À titre fictif, 20 % de réduction sur 5 unités laisse 4 unités, tandis que 10 % sur 4 unités laisse 3,60. Le second pourcentage est plus faible, mais le coût final est inférieur. Cette comparaison ne recommande aucune plateforme : elle montre pourquoi une décision fondée uniquement sur le nombre le plus visible peut être trompeuse.

## Vérifiez le résultat sans confondre économie et performance

Après une opération que vous aviez déjà prévue, consultez les frais effectifs et la manière dont le bénéfice confirmé a été appliqué. Utilisez soit le coût net, soit le coût brut accompagné du crédit correspondant, sans soustraire deux fois le même avantage. La variation de valeur de l’actif reste une question distincte. Une commission réduite peut accompagner une perte de marché. Ne multipliez pas les opérations pour obtenir une économie affichée plus importante : le coût total peut augmenter malgré la réduction unitaire.

## Questions fréquentes

### Une réduction de 20 % signifie-t-elle vingt points de moins ?

Non. Il s’agit d’une réduction relative de la commission éligible. Dans l’exemple pédagogique, 0,10 % devient 0,08 %, soit une différence de 0,02 point de pourcentage, et non de vingt points.

### Le montant déposé constitue-t-il la base du bénéfice ?

L’offre décrite concerne les frais de négociation éligibles, pas une restitution d’une fraction du dépôt. Identifiez le coût effectivement couvert avant d’appliquer le pourcentage confirmé pour votre compte.

### Faut-il retenir systématiquement le maximum annoncé ?

Non. « Jusqu’à » exprime un plafond d’offre. Si votre compte affiche une autre condition ou si une opération est exclue, utilisez cette information dans le calcul. Une estimation honnête doit refléter votre situation, pas le scénario le plus avantageux possible.
