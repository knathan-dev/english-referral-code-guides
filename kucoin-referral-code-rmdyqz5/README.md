## An order and a fill are different records

An order expresses an instruction: what you want to buy or sell, how much, and under which price or timing conditions. A fill records an actual match. One order may generate one fill, several fills, or none at all.

Imagine an order intended to purchase 1,500 USDT worth of an asset. If only 1,000 USDT worth has actually executed, a calculation based on the full 1,500 USDT would overstate the completed activity. The outstanding part is still an instruction, subject to its conditions, rather than a purchase that has already happened.

KuCoin's [order-lifecycle documentation](https://www.kucoin.com/docs-new/terms-definitions) distinguishes open portions from completed or canceled orders. That distinction is useful even if you never use an API: the interface's order summary and trade history can describe different stages of the same instruction.

## One limit order can contain more than one fee classification

KuCoin's [maker and taker explanation](https://www.kucoin.com/support/360015207133) states that an immediately matched portion can be charged as taker activity, while a remaining portion that enters the book can later be treated as maker activity. Therefore, “I used a limit order” is not enough information to assign a single fee rate to all of its executions.

Keep the execution details that establish price, quantity, liquidity classification and fee. If a display gives only an average price, use the underlying fills when investigating a discrepancy. An average can summarize what happened without explaining why the total fee differs from a calculation using one assumed rate.

This is not a reason to choose an unnecessarily complicated order. It is simply a way to interpret an order that has already filled in stages. A referral identifier does not determine the way the matching engine will execute that instruction.

## Reserved funds are not automatically spent fees

An open order can reduce the balance available for other orders because funds are reserved. That reduced available balance should not immediately be described as a fee paid. The amount may include the unexecuted purchase value and a fee allowance.

KuCoin's order documentation describes a fee hold during order processing and adjustment for maker execution. When reconciling an account, distinguish the amount reserved at placement from the final fee on a completed fill. A temporary hold and a final expense answer different questions.

If you cancel an unfilled remainder, review what is released and what was already executed. Cancellation does not reverse an earlier completed purchase or make its fee disappear. Use the final order status and balance records together; avoid assuming that a canceled order means every part of the original instruction was undone.
