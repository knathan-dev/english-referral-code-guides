## 비율을 실제 예상 비용으로 바꾸어 보기

예를 들어 한 거래는 수수료가 없고 다른 거래는 수수료가 있지만 할인을 제공한다고 가정해 보겠습니다. 숫자 비교는 같은 상품과 같은 거래 조건에서 해야 합니다. 서로 다른 실행 결과나 사용 경로를 무시한 채 할인율이 더 높다는 이유로 전체 비용이 낮다고 판단할 수는 없습니다.
