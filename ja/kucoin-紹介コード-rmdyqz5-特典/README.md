## 注文と約定は同じ単位とは限らない

注文は、どの条件でどれだけ売買したいかという指示です。一方、約定の明細は実際に成立した部分を示します。一つの注文について複数の明細が表示されている場合、明細の数だけ別の取引判断をしたとは限りません。まず何を数えているのかをそろえることが大切です。

表示に注文や約定を区別する識別情報がある場合は、必要な範囲で残しておくと照合に役立ちます。ただし、どの画面でも同じ項目が表示されるとは決めつけません。自分が見ている画面の情報と、別の出力形式の情報が同じ範囲かを確かめてから比較してください。

## 手数料の通貨を省略しない

手数料を控えるときは、金額と通貨を一緒に残します。0.01という数だけでは、どの費用なのか分かりません。複数の通貨が使われている記録を集計するなら、同じ通貨の項目を分けるか、換算方法を明示する必要があります。

換算する場合は、どの時点の価格を基準にしたかも記録します。取引時点の換算値と現在の評価額を混ぜると、紹介条件の差ではなく価格評価の差が入り込みます。ここで税務上の評価方法を指定しているわけではなく、比較の前提をそろえるための説明です。

元の通貨と金額は、換算後も残しておくと後から見直せます。丸めた数字しか保存しないと、小さな差が条件の違いによるものか、丸め方によるものかを区別しにくくなります。ただし、資料にない桁を想像で補い、実際より精密な記録として見せないでください。
