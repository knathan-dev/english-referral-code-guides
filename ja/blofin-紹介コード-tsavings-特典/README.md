# BloFin 紹介コード TSAVINGS：対象取引手数料の最大20%軽減と明細の読み分け

**BloFin 紹介コード TSAVINGS** には、紹介元から**対象となる取引手数料を最大20%軽減する特典**が案内されています。実際の割合、対象商品、適用期間は、利用するアカウントに表示される条件で確認してください。[BloFinの紹介リンク](https://partner.blofin.com/d/TSAVINGS)は、その確認を始めるための入口です。現金の入会祝いが約束されているわけではありません。本記事では、残高の変化をすべて特典と結び付けず、明細の費目を分けて読む方法を説明します。

## 残高の増減と費用の発生は同じ意味ではない

口座の数字が前日と違っていても、その差額だけで手数料や紹介特典の額は分かりません。自分で資金を移した場合と、取引に伴う費用が記録された場合では、数字が動いた理由が異なります。まず各記録が何を表しているかを調べ、その後で合計する順番にしましょう。

たとえば、残高が増えたからといって、その増加分をすべて還元として扱うことはできません。反対に、残高が減ったからといって、紹介が反映されていないとも限りません。口座全体の結果と、一つの対象手数料に適用される条件は、別々に確認する必要があります。

この区別をつけるために、最初から複雑な帳簿を作る必要はありません。「自分による資金移動」「取引に関係する記録」「内容をまだ確認していない項目」のように、意味が分かる範囲で整理します。分からない項目を無理に割引の計算へ入れないことが大切です。

## 対象手数料だけを一つのまとまりにする

紹介特典の計算では、条件で対象と確認できた取引手数料を取り出します。利用に伴って発生した費用であっても、同じ特典が適用されるとは限りません。「口座に関係する費用」と「この紹介の対象費用」を同じ集合として扱わないようにしてください。

仮の例として、ある期間に確認した費用が合計18単位あり、そのうち対象手数料が11単位だったとします。20%の軽減が確認できているなら、計算上の軽減額は2.2単位です。18単位全体に20%を掛けた3.6単位ではありません。これは計算方法を説明する例であり、BloFinの実際の料金を示すものではありません。

対象かどうかが不明な費目は、いったん未確認として残します。見た目の似た名称や、同じ日に発生したという理由だけでまとめると、計算は正確でも出発点が間違ってしまいます。後から条件が分かれば、その項目だけを見直せば十分です。

## 表示された料金が割引前か割引後かを確かめる

明細にある数字が、特典適用前の料金なのか、すでに調整された最終料金なのかを確認しましょう。もし割引後の数字に同じ割合をもう一度掛ければ、存在が確認されていない二重の軽減を計算することになります。

たとえば、仮の元の料金が5単位で、20%軽減後の4単位が表示されている場合、さらに0.8単位を差し引く理由はありません。一方、元の料金と別の調整額が記録される条件なら、その二つを対応させます。どちらの表示方式なのかは、実際のアカウントの説明に従ってください。

「最大20%」という案内だけでは、表示方式や反映時期までは分かりません。そこを想像で補うと、正しく処理された記録でも誤りに見えることがあります。数字を訂正する前に、その数字の意味を確認する方が近道です。

## 未確認の還元を使える資金に含めない

将来の調整を見込んだ金額と、すでに利用可能と確認できる残高は区別します。紹介特典の割合が分かっていても、対象となる費用や反映条件が未確認なら、予想額はまだ予想です。それを前提に追加の取引や支払いを決めないようにしましょう。

この考え方は、特定の反映日を断定するものではありません。実際の条件で時期が示されているなら、その内容を確認します。示されていないなら、他の利用者の経験から同じ日程だと推測せず、自分のアカウントに適用される説明を求めます。

予想より小さな特典しか確認できなかった場合も、口座全体の数字を動かして帳尻を合わせる必要はありません。対象範囲や実際の割合を直して、残る費用を把握します。大きな見積もりを維持するより、確認できた金額を使う方が次の判断に役立ちます。

## 問い合わせには費目と計算の前提を添える

確認が必要なら、関連する取引の識別情報、対象商品、料金の単位、自分が使った割合を整理します。「残高が思ったより少ない」という説明より、「この手数料は紹介条件の対象で、表示額に軽減が含まれているか」という質問の方が、調べる範囲を明確にできます。

BloFinの公式セキュリティ案内も参考にし、問い合わせとアカウントへのアクセスを混同しないでください。TSAVINGSは公開の紹介用識別子ですが、パスワードや認証用の値は別の情報です。特典の確認のために第三者へ口座の操作権限を渡す必要はありません。

資料を共有する場合は、質問に関係しない残高や個人情報まで一緒に送らないようにします。必要な文脈は残しつつ、確認したい費目に焦点を絞ることで、回答も後から読み直しやすくなります。

## 集計の単位と期間もそろえる

異なる単位で記録された金額は、そのまま足し合わせないようにします。必要なら共通の通貨へ換算できますが、どの時点の値を使ったのかを明記してください。元の数量も残しておけば、価格の変化による差と、紹介による軽減の差を区別しやすくなります。

同じ単位でも、対象期間が違えば比較の意味が変わります。ある日に記録された調整が、必ずその日の取引だけを対象にするとは限りません。実際の条件や記録から対応を確認し、分からない場合は期間を決め付けずに質問しましょう。

仮に先月の対象費用に関する調整を今月の料金だけで割ると、見かけの還元率が不自然に大きくなることがあります。計算式を複雑にする前に、分子と分母が同じ活動を表しているかを確認します。少ない項目でも、単位と期間がそろっていれば意味のある比較になります。

## 月末には未解決の項目を残したまま区切ってよい

期間の終わりに全項目を必ず解決しようとして、根拠のない分類をする必要はありません。確認済みの対象手数料、確認済みの調整、未確認の項目を分ければ、その時点で説明できる結果を出せます。未確認分があること自体も重要な情報です。

特典の合計額が増えた場合は、元の手数料も増えていないかを確認します。還元が大きいことと、最終的な支出が小さいことは同じではありません。紹介の数字を増やすためだけに取引を追加せず、本来の利用目的と費用の上限を維持してください。

次の期間には、解決した項目の説明だけを引き継ぎます。古い仮定や未確認の最大割合を、いつまでも確定条件として残さないようにしましょう。明細を読める状態にすることが、紹介特典を落ち着いて評価する土台になります。

## よくある質問

### TSAVINGSを入力すれば現金が必ず受け取れますか？

ここで案内されているのは対象取引手数料の軽減です。現金の入会祝いが確約されたものではなく、実際の割合と条件をアカウントで確認する必要があります。

### 口座の費用を全部まとめて20%引きにしてよいですか？

対象と確認できた費用だけが計算の基礎になります。別の費目や未確認の項目を、同じ条件だと推測して加えないでください。

### 計算と表示が違うときは何を確認しますか？

対象範囲、適用割合、表示が割引前か割引後かを確認します。そのうえで、関連する記録と計算の前提を示して公式窓口へ質問します。
