# Metric 紹介コード carcosa: 対象ポイント10%加算と条件を読み直すタイミング

**Metric 紹介コード carcosa**には、対象となるポイントを10%加算する特典が案内されています。ただし、コード固有の加算率を個別ウォレットで独立に確認した結果ではありません。利用するウォレットに表示される紹介状態と最新の条件を確かめてください。この記事では、一度読んだ説明をそのまま使い続けず、参加内容や案内が変わったときに何を見直すべきかを整理します。

## 「以前確認した」と「今も適用される」を分ける

紹介特典を理解したつもりでも、後から見る画面では別の期間や活動を対象にしている場合があります。まず、以前読んだ説明が何についての説明だったかを確認しましょう。ウォレット、対象の活動、計算期間が違えば、同じ10%という表示でも比較する前提が変わります。

ここで、Metricが特定の条件を変更したと主張しているわけではありません。利用者が保存した説明と現在の案内を比較するための考え方です。変更の有無が分からない段階では、前の条件が続いているとも、特典が終了したとも決めつけないことが大切です。

公式のポイント資料では、対象となる参加や週単位のポイントについて説明されています。自分が確認したい期間に関係する箇所を読み、紹介の条件と結び付けて理解してください。一般的なプログラム説明だけで、特定ウォレットへのコード適用まで確認できたと扱うのは早計です。

## 読み直すきっかけを具体的に決めておく

見直しのきっかけは、特典の数字が変わったときだけではありません。使うウォレットを変えた、別の活動を始めようとしている、対象期間が分からなくなった、以前の説明と画面の文言が合わないといった場面でも確認が必要になります。

たとえば、これまで一つの活動だけを行っていた人が、別の機能にも関心を持ったとします。前の活動でポイントの説明を読んだからといって、新しい活動が同じ扱いになるとは限りません。対象と書かれているか、条件の説明があるかを先に確かめると、後から期待だけが膨らむのを防げます。

確認したい点を一度に増やしすぎないことも有効です。最初に対象活動、次に期間、最後に紹介状態というように、分からない箇所を順に整理できます。すべてを調べ終えるために入金や取引を実行する必要があると考えず、資料とサポートで解決できる質問から扱いましょう。

## 加算率が同じでも追加ポイントは変わる

仮の計算として、ある期間の対象基本ポイントが600ポイントなら、確認済みの10%加算は60ポイントです。別の期間の対象基本ポイントが350ポイントなら、同じ割合でも加算は35ポイントになります。追加分が小さくなっただけでは、割合が引き下げられた証拠にはなりません。

また、画面に表示される合計がそのまま加算対象の基本ポイントとは限りません。別の項目や過去の分が含まれるときには、現在の対象額を確認してから掛け算をしてください。この数値例はMetricの実際の付与条件や獲得量を示すものではなく、比較する基礎をそろえるための説明です。

ポイント数から現金価値を自動的に導くこともできません。将来のトークン、交換比率、配布日、出金可否などは、それぞれ明示された根拠が必要です。分からない価値を推測で埋めると、単なるプログラム上の増加を確定した利益として受け止めてしまいます。

## ウォレットを変える前に紹介の範囲を確認する

提供された招待経路を使う場合は、**carcosa**をそのまま確認してください。ブラウザーで複数のウォレットを切り替えているなら、いま選択されているアドレスを確かめてから紹介情報を読みます。別のウォレットで見た表示を、現在のウォレットにも適用される情報として扱わないようにしましょう。

以前のウォレットから資産を移したという事実だけで、紹介関係も移ったと結論付けることはできません。資産の移動とプログラムのアカウント上の扱いは別に確認する必要があります。分からない場合は、移動で解決を試みる前に、対象ウォレットの状態を運営者へ問い合わせる方が明確です。

問い合わせに必要な情報と、渡してはいけない情報も分けてください。確認したいアドレスや画面の一部が役立つ場合はありますが、秘密鍵や復元フレーズを共有する理由にはなりません。第三者にウォレットの操作を任せることが紹介特典の説明を受ける条件になるわけではありません。

## 差が見つかったら、確認できた事実から質問する

問い合わせでは、以前見た説明、現在の表示、知りたい点の三つを短くまとめると伝わりやすくなります。たとえば、対象期間の説明が見当たらないので現在の活動が加算対象か確認したい、と質問できます。まだ確定していない加算額を、未払いの確定債権のように表現する必要はありません。

回答がプログラム全体の説明なのか、自分のウォレットについての確認なのかも読み分けましょう。一般的な案内を受け取っても、個別の適用状態が解決していないことがあります。回答の範囲が曖昧なら、どの部分まで確認されたのかを追加で明確にできます。

画面を添えるときには、質問と無関係な残高や個人情報を隠してください。日付や表示の文言が必要な場合でも、取引履歴全体を公開する必要はありません。自分が何を確認したいのかを絞ると、提供する情報も必要な範囲に収めやすくなります。

参加を続けるかどうかは、ポイント以外の目的も含めて判断しましょう。条件が分からない間に活動量を増やしても、期待した扱いになるとは限りません。手数料や保有資産の価格変動は現実の結果として発生し得ます。特典を確認するためだけに新しい取引を作ることは避け、必要なら判断を保留できます。

## よくある質問

### 前回より追加ポイントが少なければ、10%の特典が消えたのでしょうか？

それだけでは分かりません。対象基本ポイントや対象期間が違えば、同じ割合でも追加分は変わります。比較する基礎をそろえたうえで、現在の紹介状態と条件を確認してください。

### ウォレットを切り替えても紹介関係は同じですか？

自動的に同じだとは扱わないでください。実際に利用するウォレットについて確認する必要があります。資産を移したことや同じブラウザーを使っていることだけで適用状態は確定しません。

### 以前の説明と新しい画面のどちらを信じればよいですか？

まず対象期間や活動が同じかを確認し、解決しない部分を運営者に問い合わせましょう。古い画面だけで将来の条件を保証したり、新しい表示を見ただけで過去の記録まで誤りと決めたりしないことが重要です。

### 10%加算なら資産全体も10%増えるのでしょうか？

その意味ではありません。案内されているのは対象ポイントの加算です。資産の収益率、現金の支払い、損失補償とは区別し、金銭的な価値が未確定なら未確定のまま扱ってください。
