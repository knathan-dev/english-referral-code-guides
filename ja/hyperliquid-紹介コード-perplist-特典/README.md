# Hyperliquid 紹介コード PERPLIST: 最初の取引高2,500万ドルまで手数料4%割引

**Hyperliquid 紹介コード PERPLIST**では、公式紹介制度に基づき、**最初の取引高2,500万ドル分にかかる取引手数料の4%割引**を利用できる場合があります。ボールトとサブアカウントは対象外です。実際に使うウォレットの紹介登録を確認してから判断してください。本稿では、画面や接続先を変えたときに「どのウォレットの取引を見ているのか」を確かめる手順を整理します。

## 接続中のウォレットと、確認したい取引を一致させる

紹介リンクを開いたブラウザーと、実際に取引するウォレットを同じものとして考えると混乱しやすくなります。ブラウザーで招待ページを表示できたことは、その中で選択できるすべてのウォレットに紹介関係が登録された証拠ではありません。まず、現在選んでいるアドレスが自分の意図したものかを確認しましょう。

たとえば、以前の確認に使ったウォレットと、今回接続したウォレットが違う場合を考えます。以前保存した紹介画面を今回の取引の根拠に使う前に、どのアドレスについて保存した記録かを読み直す必要があります。表示される残高が似ていても、同じ利用主体だとは限りません。

個人用の記録には、ウォレットを識別できる情報と確認日を残します。公開する記事や投稿に口座情報を載せる必要はありません。目的は自分で照合できることです。復元フレーズや秘密鍵は紹介条件の確認に使う資料ではなく、他人に渡す必要もありません。

## 紹介状態は、使うウォレットの画面で確かめる

提供されたPERPLISTの招待経路を利用する場合は、大文字の表記を保ち、対象ウォレットの紹介情報を確認してください。URLにコードが入っていることと、利用を終えた登録の状態は別々の情報です。リンクを保存しただけで確認を完了したと考えないようにします。

確認した状態を記録しておくと、後日手数料に疑問が生じたときに質問を分けられます。紹介関係自体の問題なのか、ある取引の対象範囲の問題なのか、別の費用を見ているのかを整理できるためです。すべての違いをコード入力の失敗として扱うと、必要のない再操作につながります。

すでに利用しているウォレットについて不明点がある場合は、現在の公式説明と表示内容を確認します。再度リンクを開けば過去の取引まで条件が変わる、という推測はしないでください。本稿は、個別ウォレットへのPERPLISTの適用を実測した結果を示すものではありません。

## メインの利用と、対象外の仕組みを混ぜない

公式紹介文書は、ボールトとサブアカウントを対象外としています。したがって、関連する活動をすべて一つの紹介特典にまとめて計算することはできません。画面の切り替えでどの口座や仕組みを扱っているかが変わった場合は、その範囲を先に確認します。

仮に、自分の通常の取引について紹介状態を確認し、別の画面でボールトに関する記録を見たとします。前者の確認を後者にもそのまま使うと、対象外の活動に割引を見込んでしまいます。ひとつのサービス内に表示されることと、同じ紹介条件が適用されることは同じではありません。

口座構成を変えることを、割引範囲を増やす方法として考えないことも大切です。新しい表示名や別の操作画面があるだけで、対象取引高が初期化されるといった条件は確認できません。仕組みを変える必要があるなら、まずその用途と適用範囲を公式案内で理解しましょう。

## インターフェースが変わったら費用の内訳を見直す

同じウォレットを使っていても、取引画面やインターフェースの違いが費用の確認に影響することがあります。公式のビルダーコード文書は、インターフェースに関する別の手数料を説明しています。画面に表示された総額すべてが紹介割引の対象だとは仮定しないでください。

比較するときは、どのウォレット、どの取引、どの費用を見ているかをそろえます。単に合計額が以前より大きいというだけでは、紹介登録が消えたとは判断できません。取引規模や対象手数料、別途表示される費用など、比較条件の違いを先に調べます。

ここで必要なのは、すべての仕組みを一度に覚えることではありません。費用の名前と計算基準を確認し、紹介制度が説明する手数料とその他の項目を分けることです。分からない項目は、最大限有利な条件を当てはめるより、未確認として残したほうが正確です。

## 4%と2,500万ドルを別の役割で読む

4%は対象手数料の割引率であり、取引額全体の4%が戻る意味ではありません。2,500万ドルは最初の対象取引高の範囲を示します。入金額や口座残高を意味せず、その金額を入れる必要があるという説明でもありません。

計算方法の例として、紹介割引の対象となる手数料が25ドルなら、その4%は1ドルです。これは実際の口座に対する料金見積もりではありません。また、表示された25ドルがすでに割引後の費用であれば、さらに4%を差し引く計算はできません。実際の表示の意味を確かめてから使います。

対象範囲の上限に近づいた場合も、その範囲を使い切る必要はありません。紹介特典は予定していた活動の費用を評価するための情報です。割引を増やすために取引を増やせば、費用や価格変動への負担も増える可能性があります。残りの対象取引高を売買目標にしないでください。

最後に、地域や口座に適用される利用条件を確認します。日本語の案内が読めることは、日本で特定の商品を利用できることの証明ではありません。紹介の適用、サービスの利用資格、実際の取引判断は、それぞれの根拠を持って確認する必要があります。

## よくある質問

### ウォレットを切り替えても紹介登録は同じですか？

自動的に同じだとは考えないでください。実際に使うウォレットの紹介状態を確認する必要があります。過去に別のアドレスで保存した画面は、今回のアドレスの適用証明にはなりません。

### ボールトやサブアカウントにも4%割引を計算できますか？

公式紹介文書はボールトとサブアカウントを除外しています。通常のウォレットで確認した紹介条件を、関連するすべての活動に広げて使わないでください。

### PERPLISTの特典を確認するために取引すべきですか？

必要のない取引を追加する必要はありません。まず紹介状態と現在の条件を確認し、不明点は公式案内や適切なサポート経路で解消します。割引は取引利益や損失回避を保証しません。
