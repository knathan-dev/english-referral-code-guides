## 記録には三つの時点を残す

個人用の記録では、取引が行われた日、リベート計算の対象期間、実際に受け取った日を分けると整理しやすくなります。受取日だけを見て取引日に対応させると、別の期間の活動を比較してしまう可能性があります。これは特定の支払い遅延があるという主張ではなく、記録の範囲を合わせる方法です。

たとえば、ある日に金額が表示された場合、その表示がどの取引期間に関するものかを確かめます。前に見ていた概算と同じ対象なのか、別の口座が含まれているのかも確認します。日付が近いというだけでは、二つの数字が同じ活動を示すとは限りません。

期間の開始と終了を記録するときは、画面がどの時間基準を使っているかも確認すると役立ちます。自分のメモの日付と運営者の集計が違って見える場合、まず比較の境界をそろえます。根拠がないまま差額を未払い、あるいは追加特典と決めつけないでください。

## よくある質問
