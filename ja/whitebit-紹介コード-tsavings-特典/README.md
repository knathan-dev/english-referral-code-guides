# WhiteBIT 紹介コード TSAVINGS：対象取引手数料の最大20%軽減と無理のない予算の作り方

**WhiteBIT 紹介コード TSAVINGS** には、紹介元から**対象取引手数料を最大20%軽減する特典**が案内されています。実際の割合、対象商品、期間はWhiteBITがアカウントに適用する条件で確認してください。[WhiteBITの紹介リンク](https://whitebit.com/a/TSAVINGS)を検討するときは、最大の特典が確認できない場合にも説明できる予算を用意すると、判断を急がずに済みます。ここでは割引ありと未確認の二つの見積もりを整理します。

## 使える金額と期待する軽減額を分ける

自分が利用に充てられる金額は、現在の資金や予定している支出から決めます。まだ確認していない紹介特典を足して、利用上限を大きくしないようにしましょう。期待する軽減額は、使える資金とは別の情報です。

たとえば、最大割合が適用されれば予算に収まるというだけでは、その割合が未確認の間は計画が成立したとは言えません。条件が分かるまで保留するか、軽減を含めなくても説明できる小さな計画を考える余地があります。

紹介を検討した時点で、必ず入金や取引を行う義務はありません。情報を読む段階で、自分の目的に合わないと分かることもあります。すでに調べた時間を取り戻そうとして、別の支出を増やさないことが大切です。

## 基本の見積もりには確認できた料金を使う

最初の見積もりでは、対象となる活動にどの料金が適用されるかを確認します。別の商品や別の条件で見た最も低い数字を、そのまま自分の予定へ移さないでください。料金の基礎が不明なら、割引後の数字も確定しません。

取引手数料と、資金を動かす際の費用は分けて扱います。紹介元が案内する取引手数料の軽減から、出金費用も同じ割合で下がるという結論は出せません。費目ごとに確認できた条件を残します。

数字を細かくすることより、どの活動に関する数字か分かることが重要です。商品、予定額、料金の単位、確認した日付を添えておけば、条件が変わったときにどの箇所を修正すればよいか判断できます。

## 軽減なしと確認済みの軽減を並べる

仮に対象手数料の見積もりが13単位だとします。軽減を含めない場合は13単位です。20%の適用が確認できた場合は2.6単位が軽減され、残る料金は10.4単位になります。これは計算の例であり、WhiteBITの実際の料金を示すものではありません。

もし実際に確認できた割合が8%なら、軽減額は1.04単位、残る料金は11.96単位です。最大値に届かなくても、確認できた条件を使って計算すれば予算の役割を果たします。大きい割合に数字を合わせる必要はありません。

二つの見積もりを並べる目的は、最も低い費用を強調することではなく、未確認事項の影響を知ることです。その差が利用判断を左右するなら、実行前に条件を明確にする優先度が高いと分かります。

## 一部だけが対象になる場合も考える

活動全体の費用が分かっていても、その全額が紹介の対象とは限りません。対象範囲が確認できている部分と、確認できていない部分を分けます。最大割合と最大範囲を同時に仮定すると、軽減を過大に見積もりやすくなります。

仮の総費用が16単位で、そのうち10単位だけが対象なら、20%による軽減は2単位です。残る全体費用は14単位となります。16単位すべてを20%軽減する計算は、全額が対象だと確認された場合に限ります。

将来利用するかもしれない商品を、いま確認した対象範囲へ自動的に加えないようにしましょう。予定が変われば、商品と費目の確認も更新します。紹介コードが同じでも、分析に含める活動は変わる可能性があります。

## 費用を払えることと操作を理解することは別

予算に収まると分かっても、送金先や口座設定が適切だという証明にはなりません。WhiteBITは公式資料でアカウント設定と出金手続きを案内しています。実際に行う操作に関係する説明を読み、費用とは別に理解を確認します。

たとえば、宛先を変更する予定があるなら、その変更に関係する手順を確かめます。紹介特典の有無は宛先の正しさを保証しません。逆に、宛先を確認できても、取引手数料の条件が確認できたことにはなりません。

確認の目的が異なることを意識すれば、一つの成功表示から何もかも完了したと受け取る誤りを減らせます。自分が何を確認したのかを狭く正確に記録する方が、「準備完了」という一言だけを残すより役立ちます。

## 予算に余裕があっても活動を増やす必要はない

軽減が確認できたことで、想定より費用が小さくなる場合があります。その差額を必ず追加取引に使う必要はありません。元の利用目的が満たされているなら、費用が少なく済んだ結果として残せます。

予算の上限は、使い切る目標ではありません。上限に近づくまで活動を増やすと、紹介による節約のために別の支出や価格変動への影響を引き受ける形になります。軽減額が増えても、残る費用が下がるとは限りません。

一方、予定より費用が大きくなるなら、最大の特典が後で補うはずだと考えず、活動の内容を見直します。確認できていない条件に依存しないことが、予算を判断の道具として使うための基本です。

## 実績が出たら仮定を一つずつ置き換える

適切な目的で活動した後は、実際の手数料と確認済みの調整を見積もりに反映します。表示がすでに軽減後の料金なら、同じ割合を再度差し引かないでください。別の調整がある条件なら、対応する対象活動を確認します。

予想と違った箇所は、元の料金、対象範囲、適用割合、表示方法のどれに関する違いかを整理します。原因が分からないまま合計だけを修正すると、次の見積もりで同じ混乱が起きます。答えが出ない部分は未確認と残せます。

問い合わせでは、関連する記録と計算の前提を示します。TSAVINGSという公開の紹介用識別子を伝えることと、口座のパスワードを渡すことは別です。確認に不要な個人情報やアクセス情報を共有しないようにしましょう。

## 次の判断に使う記録を短く整える

最後に残すのは、対象商品、確認した割合、対象費用、残る費用と、その確認日です。過去の最大割合を何度もコピーするより、現在の条件がどこで確認されたか分かる記録の方が、後日の判断に使えます。

条件が変わった場合は、以前の記録を誤りだったことにせず、適用時点を分けます。過去に正しかった見積もりと、現在使うべき見積もりは両立します。必要な修正だけを行えば、毎回すべてを調べ直す必要も減らせます。

紹介の価値は、あくまで確認できた対象費用の軽減として評価します。利益、損失の補償、すべての費用の削減を約束するものではありません。この範囲を守ると、最大値が確認できた場合にも、できなかった場合にも落ち着いて判断できます。

## よくある質問

### 最大20%が確認できるまで予算を作れませんか？

軽減を含めない見積もりと、条件が成立した場合の見積もりを分けて作れます。ただし、未確認の低い費用を確定値として使わないでください。

### 特典で浮いた金額は取引に使うべきですか？

使い切る必要はありません。活動の目的と上限を独立して決め、紹介額を増やすためだけの追加活動は避けます。

### TSAVINGSは出金手数料も下げますか？

ここで案内されているのは対象取引手数料の軽減です。出金費用などの別の費目は、それぞれの適用条件を確認してください。
