# OKX 紹介コード TSAVINGS：対象取引手数料が最大20%軽減される特典と料金資料の読み分け

OKX 紹介コード TSAVINGSには、対象となる取引手数料が最大20%軽減される紹介特典が案内されています。実際に適用される割合、対象商品、口座構成や利用資格は、口座の条件で確認してください。複数の公式ページで違う数字を見つけたときは、すぐに矛盾だと判断せず、それぞれがどの地域、商品、時点を説明しているかを整理すると、確認すべき点が明確になります。

## まず自分の質問を一文にする

料金資料を探す前に、何を知りたいのかを書いておきます。たとえば、予定している商品の通常手数料なのか、紹介特典の割合なのか、別の口座構成でも対象になるかという質問なのかを分けます。同じ検索結果に表示されても、これらの質問に答える資料は同一とは限りません。

「一番安い料金を知りたい」という目的だけでは、条件の違う数字を選びやすくなります。自分が利用できる口座と商品を先に特定し、その範囲の情報を読むことが必要です。日本語で資料が読めることだけで、日本からのサービス利用や特定商品の利用資格が確定するとは考えないでください。

また、誰かの口座で確認できた条件は、その人の状況についての情報です。自分にも同じ条件が付くかは別に確認します。紹介コードの特典を比較する際も、他人の画面をそのまま基準にするより、自分の確認したい項目をそろえるほうが、後の食い違いを減らせます。

## TSAVINGSの案内と口座の表示を分ける

提供された紹介リンクを開き、TSAVINGSというコードと案内内容を確認します。リンク先の説明は、紹介を通じて何が案内されているかを知る手掛かりです。一方、実際の口座に何が割り当てられたかは、登録後の条件や公式の回答で確認する必要があります。

すでに口座を利用している場合は、同じリンクを開くだけで紹介関係が変更されるとは保証できません。現在の登録状態を伝え、自分のケースで可能なことを確認してください。別口座を作って条件を再現することを前提にせず、既存の口座について質問を具体化しましょう。

確認できた内容には日付と対象を添えます。最大20%という数字だけを残すと、別の商品を使うときにも同じ条件だと誤解しやすくなります。対象範囲が分からないときは、割合の計算を先に進めるより、どの手数料を基準にするのかを明確にするほうが重要です。

## 地域別の資料は対象を見て読む

OKXには地域に関係する料金説明があり、公開資料の数字を読む際には適用範囲が重要です。たとえば、別地域向けの説明が正しい内容であっても、自分の口座の料金をそのまま示しているとは限りません。資料の見出しだけでなく、誰に向けた説明なのかを確認してください。

この注意は、特定の地域で料金が必ず高い、低いと主張するものではありません。比較の前提をそろえるための方法です。対象が違う資料を並べるなら、その違いをメモに残し、同じ口座の料金変更だと決めつけないようにします。更新日と適用開始日も同じ意味とは限りません。

資料の対象が自分の状況に合うか分からない場合は、その部分を質問します。一般的な資料を大量に保存するより、商品名と口座の条件を示して「この説明が適用されるか」と確認するほうが、回答の範囲を理解しやすくなります。分からない箇所を推測で埋める必要はありません。

## 基本手数料と紹介特典を別の段階で計算する

仮に、ある対象取引の基本手数料が10単位で、確認済みの紹介特典が20%だったとします。軽減分は2単位、軽減後は8単位です。別の時点で基本手数料が8単位になったという仮定なら、同じ20%の軽減分は1.6単位、残る手数料は6.4単位になります。

この例は実際のOKX料金や料金変更を示していません。基本手数料の変化と紹介特典による変化を分けるための計算です。最初の10単位と後の6.4単位だけを比べて、差額すべてが紹介コードの効果だと説明すると、基本料金の変化まで特典に含めてしまいます。

予定していた取引の数量や商品まで変わった場合は、さらに比較条件が異なります。まず同じ条件で考えられる範囲をそろえ、分からない要素は仮定として明示しましょう。試算が細かい数字になっても、前提が未確認なら、確定した節約額として受け取ることはできません。

## 口座構成が違うときは対象口座を確認する

公式資料では、サブアカウントや口座モード、API接続などについても説明されています。外部ツールや複数の口座構成を使う場合は、どの口座で取引が行われ、どこに手数料が記録されるかを先に把握してください。まとめて表示される残高だけでは、紹介特典の対象を判断できないことがあります。

アクセス権限と紹介条件にも役割の違いがあります。ツールから口座情報を見られることは、その口座に特定の紹介条件が付いた証明ではありません。反対に、紹介条件が確認できても、第三者に口座を操作する権限を与える理由にはなりません。それぞれの確認を独立して扱います。

口座構成を使い分けていない人が、特典のためだけに複雑な設定を始める必要はありません。必要な機能を理解し、現在の使い方に関係する条件を確認するだけで十分な場合があります。仕組みを増やせば自動的に手数料が下がるという前提は置かないでください。

## 食い違いは資料の範囲を添えて問い合わせる

疑問が残ったら、資料のURL、確認日、対象となる口座や商品、知りたい手数料を整理します。「二つの数字が違う」というだけでなく、同じ条件を説明していると思った理由を示すと、どこを読み違えていたかを確認しやすくなります。相手の回答も適用範囲と一緒に残しましょう。

手数料の相談に、パスワード、認証コード、APIの秘密情報を添える必要はありません。取引の例が必要なら、不要な個人情報を隠し、公式の窓口で必要な範囲だけを共有します。紹介の確認とアクセス設定の相談を混ぜないことが、安全で分かりやすい問い合わせにつながります。

最後に、条件が確認できるまでは特典を使い切るための取引を増やさないでください。費用の軽減は、市場の利益や損失とは別の話です。予定していた取引の費用を理解することを目的にすれば、数字を大きくするために数量やリスクを増やす必要はありません。

比較の結論を残すときは、確認できた条件と未確認の仮定を分けて記載してください。資料の対象がそろった比較なのか、説明のために数字を置いた試算なのかが後から読んでも分かるようにすると、次の利用時に誤った前提を引き継がずに済みます。

## よくある質問

### TSAVINGSで地域ごとの条件を無視できますか？

できません。紹介特典は利用資格や地域、商品の条件に従います。別地域の資料で見た数字を、自分にも適用される確定条件として扱わないでください。

### 20%をほかの割引と足してよいですか？

組み合わせが確認できるまでは足さないでください。同じ手数料に対する別の制度なのか、別項目の費用なのかによって意味が変わります。対応する条件と基準額を確かめてから計算します。

### 公式資料が複数あるときは一番新しいものだけでよいですか？

日付だけでは判断できません。対象地域、商品、口座、適用時期も確認してください。新しい資料でも別の対象向けであれば、自分の取引に関する古い記録の説明にはならない場合があります。
