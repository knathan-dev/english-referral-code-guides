A saving is calculated against fees that would otherwise be payable. Paying additional fees to obtain a larger discount can increase total expenditure. Compare the amount left to pay, not only the amount described as saved. This is especially useful when an interface or spreadsheet highlights the reward while leaving the underlying increase in activity less visible.
